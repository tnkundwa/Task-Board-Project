# Infrastructure

Tools and configuration for deploying and operating the platform.

## Contents

| Directory | Purpose |
|-----------|---------|
| `scripts/` | Startup and validation scripts |
| `docker/` | Docker Compose files and MySQL init scripts |
| `kubernetes/` | Kubernetes manifests and kustomize overlays |
| `monitoring/` | Prometheus and Grafana configuration |

These directories are built as part of the infrastructure challenges in `CHALLENGE.md`.
